# Roadmap Beta — documento histórico

> Este arquivo representa o planejamento inicial do protótipo/Beta e não é mais a fonte de verdade do BUSIVS.

O projeto evoluiu para uma arquitetura de produção baseada em Cloudflare Workers, Telegram Webhook e Durable Object, diferente de vários itens previstos originalmente neste roadmap.

O histórico completo deste arquivo permanece disponível no Git.

Para o estado atual, use:

- `../CONTINUIDADE.md` — status e próxima etapa;
- `DOSSIE_MESTRE_BUSIVS.md` — regras de negócio e arquitetura atual;
- `PLANO_EVOLUCAO_BUSIVS.md` — roadmap oficial de evolução;
- `ARQUITETURA.md` — visão técnica resumida.

Não implementar itens deste roadmap histórico sem confrontá-los com o Dossiê Mestre e o código efetivo de produção.
